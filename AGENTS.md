# AGENTS.md

Учебный репозиторий RS School «Clean Code». Код намеренно написан небрежно: задача — отрефакторить
`app.js` (и привести в порядок HTML/CSS), не меняя поведение и внешний вид. Новые возможности добавлять не нужно.

## Жёсткие ограничения

- Не изменять `README.md` и `.github/workflows/check.yml`: ревьюер сравнивает их с оригиналами.
- Чек-лист поведения в `README.md` — критерий приёмки; внешний вид приложения должен остаться прежним.
- Работать в ветке форка (текущая — `refactoring`); `main` не трогать.
- Приложение без сборки: достаточно открыть `index.html` в браузере. Сборщиков, фреймворков и runtime-зависимостей нет.

## Команды

- `npm install` — заодно устанавливает Husky-хуки через `prepare`.
- `npm run lint` / `npm run lint:fix` — ESLint по всему репозиторию.
- `npm run format` / `npm run format:check` — Prettier по всему репозиторию, включая HTML, CSS и Markdown.
- Тестового раннера нет. Не добавлять тестовый фреймворк: проверка — вручную в браузере по чек-листу из `README.md`.

Pre-commit выполняет `npx lint-staged` → `prettier --check` только для файлов в индексе. CI дополнительно
запускает `prettier --check .`, поэтому перед пушем нужна полная проверка. Prettier сканирует и
неотслеживаемые файлы, так что локальные заметки тоже могут уронить `format:check`.

## Особенности инструментов

- В `package.json` стоит `"type": "module"`, но ESLint задаёт `sourceType: "script"` для `**/*.js` (кроме своего конфига). `app.js` должен остаться IIFE, а не ES-модулем.
- CI требует, чтобы в `eslint.config.js` оставались правила `no-var`, `prefer-const` и `no-console`.
- Не добавлять `index.html` или `style.css` в `.prettierignore`: CI это явно запрещает. Нужно исправлять форматирование.
- CI использует Node 22 и `package-lock.json`; для воспроизведения — `npm ci`.

## Карта кода

- `app.js` — вся логика в одном IIFE. Используется делегирование событий: один `taskClickHandler` на каждый `<li>`, который через `closest()` выбирает удаление, редактирование или чекбокс. Сохранять схему «один обработчик на элемент» и не перевешивать обработчики после каждого действия.
- `index.html` — статическая разметка со списками `#incomplete-tasks`, `#completed-tasks` и элементами `#new-task-input`, `#add-task-btn`. Класс `.editMode` переключает режим редактирования.
- `style.css` — сохранять селекторы и анимации.
- `found0problems.md` и `Untitled-1.md` — неотслеживаемые черновики автора (исходный вывод линтера и черновик отчёта). Не удалять и не коммитить без запроса.

Сообщения коммитов — на английском с префиксом (`refactor:`, `fix:`); документация и комментарии — на русском.
